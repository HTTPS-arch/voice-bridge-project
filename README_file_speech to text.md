# Speech-to-Text Module

## Description

This module converts spoken English into text using the Faster-Whisper Automatic Speech Recognition (ASR) model. It captures audio from the microphone, processes the speech, and returns the recognized text for further use.

## Features

- Captures speech from the microphone
- Converts speech to text
- Uses Faster-Whisper ASR model
- Displays recognized text
- Displays speech processing time
- Displays estimated model accuracy

## Technologies Used

- Python
- Faster-Whisper
- SpeechRecognition
- NumPy
- SciPy

## Installation

Install the required packages:

```bash
pip install -r requirements.txt
```

## Run

```bash
python text.py
```

## Output

- Recognized Text
- Processing Time
- Estimated Model Accuracy
